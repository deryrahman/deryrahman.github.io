Build a System Not Just A Goal

2026-08-30 :: Dery R Ahaddienata
#personal  #philosophy 
A half of the year has been passed. Some have got lost their commitment for the goal they’ve set in the beginning of the year. I observed this phenomenon as common yet unusual thing that might lead to frustration to some people. The goal is there for a direction, it answers the what part, but doesn’t answering precisely for the how part. That’s a common reason the goal seems unattainable. For me, I never glorify the goal, as the goal itself is useless if we didn’t do whatever need to do. Instead, it is better to focus on building a system. A system that works so well that failing to achieve is almost impossible.
